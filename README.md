# HomeLab

A personal self-hosted Linux server built using a Lenovo ThinkCentre M83. This project explores Linux system administration, networking, containerization, file sharing, and media hosting.

## Hardware

| Component | Specification |
|---|---|
| PC | Lenovo ThinkCentre M83 |
| CPU | Intel Core i5-4590 |
| RAM | 8 GB |
| Storage | Samsung 500 GB SSD |
| OS | Ubuntu Server 26.04 LTS |

## Implemented Services

| Service | Purpose | Status |
|---|---|---|
| SSH | Remote server administration | Completed |
| UFW | Firewall configuration | Completed |
| Cockpit | Web-based server management | Completed |
| Samba | Network file sharing | Completed |
| Docker | Container hosting | Completed |
| Jellyfin | Personal media server | Running |

## Technical Skills

`Linux` `Ubuntu Server` `SSH` `Networking` `Samba` `Docker` `Docker Compose` `Self-Hosting`
